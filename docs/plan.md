## المخطط 2: النية ← الأداة المستدعاة

```
                        ┌──────────────────────┐
                        │    مدير الحوار        │
                        └──────────┬───────────┘
       ┌──────────────┬────────────┼────────────┬──────────────┐
       ▼              ▼            ▼            ▼              ▼
   search         details      compare     build_plan     modify_plan
       │              │            │            │              │
       ▼              ▼            ▼            ▼              ▼
 recommender    recommender  recommender   ┌─ فحص اكتمال    planner
  .search        .details     .compare     │  ناقص→سؤال واحد .modify
                                           ▼  مكتمل ↓        (جراحي)
                                        planner.build
                                        (+feasibility إن
                                         اختار بنفسه)

   add_to_plan → saved + recommender.log (غير متزامن)
   reject      → log(pass) للكل + سؤال تشخيصي + search بمعايير جديدة
   unclear     → توضيح مستنتج من السياق (لا استدعاء)
   out_of_scope→ اعتذار + إعادة توجيه (لا استدعاء)
```

**قاعدة:** details و compare لا يستدعيان التخطيط ولا يفتحان أسئلته أبدًا.

```
المستخدم              المحادثة              التوصية(mock)  التخطيط(mock)

   │ تاريخية بدمشق»─────►│── search ───────────►│              │

   │                     │                      │              │
   │«شو قصة التاني؟»────►│ 🔍 التاني = p42       │              │
   │                     │── details(p42) ─────►│              │
   │◄─ بطاقة تفاصيل ─────│ 📝 آخر مذكور = p42    │              │
   │                     │                      │              │
   │«حلو، ضيفو»─────────►│ 🔍 ضمير = p42         │              │
   │                     │ 📝 → saved            │              │
   │◄─ «تمت الإضافة ✅»──│── log(added) ⚡ ─────►│              │
   │                     │                      │              │
   │«رتبلي خطة يومين»───►│ ✅ وجهة✓ مدة✓ مجموعة✗ │              │
   │◄─ «رايح مع مين؟»────│ (سؤال واحد فقط)       │              │
   │                     │                      │              │
   │«مع عيلتي»──────────►│ 📝 مجموعة = عائلة      │              │
   │                     │── build ────────────────────────────►│
   │◄─ خط زمني + شرح ────│◄── خطة + tradeoffs ──────────────────│
   │                     │ 📝 الخطة → الذاكرة     │              │
   │                     │                      │              │
   │«شيل السوق منها»────►│ 🔍 السوق = p08         │              │
   │                     │   (بحث بأماكن الخطة)   │              │
   │                     │── modify(remove) ───────────────────►│
   │◄─«شلته وقدمت الغدا  │◄── خطة محدثة + changes ──────────────│

```
📝 = تحديث ذاكرة العمل (إلزامي بعد كل رد) — بدونه «التاني» و«ضيفو» و«السوق» ألغاز.
⚡ = غير متزامن، لا انتظار.

## ترتيب جلسات البناء (كل جلسة: بناء + اختبار + pytest أخضر قبل التالية)

### اليوم 1

**الجلسة 1 — الأساس (~ساعة)**
- `normalizer.py`: توحيد (أ/إ/آ→ا، ة→ه، ى→ي)، إزالة تشكيل وتطويل، تقليص تكرار،
  أرقام عربية→لاتينية + `detect_language`.
- `session.py`: ConversationState + WorkingMemory (Pydantic) + تخزين/تحميل Redis
  بمفتاح الجلسة (صلاحية 24 ساعة).
- اختبارات: (قَلْعَة/قلعه/قلعــة → ناتج واحد)، (حلوووو→حلوو)، (٣→3)، كشف لغة
  لرسائل عربية/إنكليزية/مختلطة، حفظ واسترجاع جلسة.

**الجلسة 2 — النسخ الوهمية (~نصف ساعة)**
- `mocks/recommender.py` و `mocks/planner.py` ملتزمة بـ contract.md **حرفيًا**.
- بيانات ثابتة: 15–20 مكانًا سوريًا واقعيًا بحقول كاملة (منها مكان مغلق الاثنين،
  وgroup_suitability متنوعة) — القائمة في contract.md §4.
- `shared/models.py`: كائنات Pydantic للعقد كاملة.
- اختبارات: مطابقة شكل مخرجات كل أداة للعقد.

**الجلسة 3 — بيانات التدريب والمصنّف (~ساعتان)**
- توسيع `data/seed_intents.txt` (بذرة الفريق) إلى 60 مثالًا لكل نية من التسع:
  عامية سورية + فصحى + إنكليزي + مختلط، وتشمل أمثلة بعلامة `__مكان_مشار_اليه__`.
- `intent.py`: TfidfVectorizer(analyzer="char_wb", ngram_range=(2,5))
  + LogisticRegression(class_weight="balanced")، حد ثقة 0.45 → unclear،
  أمر تدريب: `python -m app.conversation.intent --train`.
- اختبارات: 5 جمل صحيحة لكل نية **غير موجودة في التدريب** + جمل غامضة → unclear.

**الجلسة 4 — محلّل الإشارات (~ساعتان)**
- `resolver.py` حسب spec.md §3-[2]: ترتيبي ← اسمي (rapidfuzz عتبة 82 على
  الاسمين معًا) ← ضمائر. يبحث في (last_recommendations + أماكن current_plan).
- اختبارات: «التاني»، «last one»، «قلعه الحصن» (خطأ إملائي)، «الحصن» (جزئي)،
  «krak»، «ضيفو»، «it»، ولا-إشارة (يرجع فارغًا)، إشارة على مكان في الخطة.

**الجلسة 5 — الكيانات (~ساعة)**
- `entities.py` بقواميس spec.md §3-[4] كاملة + أنماط المدة.
- اختبارات: «رايحين ٣ أيام عالشام مع الولاد وميزانيتنا عقد الحال»
  → destination=دمشق، duration=3، group=family، budget=low.

### اليوم 2

**الجلسة 6 — مدير الحوار (~3 ساعات، الأهم)**
- `dialogue.py` ينفّذ جدول «دليل قرار الاستدعاء» في spec.md §4 **حرفيًا**،
  بكل قواعده: الوراثة، سؤال واحد، فحص الاكتمال (أولوية: destination ثم duration
  ثم group)، feasibility قبل build عند الاختيار اليدوي، التعديل الجراحي،
  reject التشخيصي، unclear السياقي.
- **كل مسار يحدّث ذاكرة العمل قبل الإرجاع.**
- اختبارات وحدة لكل نية × (حالة مكتملة / ناقصة / بلا سياق).

**الجلسة 7 — مولّد الرد + نقطة الدخول (~ساعة)**
- `responses.py`: قوالب ar/en، 2–3 صيغ لكل موقف تُختار عشوائيًا، كل رد ينتهي
  بخطوة تالية. الرد المنظم حسب spec.md §2.5.
- `main.py`: POST /chat (session_id, user_id, message) + تحقق رأس
  X-Internal-Secret + GET /health.
- اختبارات: شكل الرد المنظم، تبديل اللغة داخل الجلسة.

**الجلسة 8 — اختبار الحوارات الكاملة (~ساعتان، هنا تُصنع الموثوقية)**
- `test_flows.py`: يشغّل الحوارات المتسلسلة عبر /chat ويتحقق بكل خطوة من:
  النية، المكان المحلول، الأداة المستدعاة، تحديث الذاكرة، لغة الرد.
- تغطية: السيناريوهات العشرة + سيناريوهات التسلسل في spec.md §5 كاملة،
  بالعربي والإنكليزي.

**الجلسة 9 — التوثيق (~نصف ساعة)**
- README: التشغيل، إعادة التدريب، إضافة نية/مدينة/قالب، أين يُستبدل كل mock.

## قواعد العمل مع كل جلسة

1. ابدأ بـ: «اقرأ CLAUDE.md و docs/spec.md [والقسم المعني] ثم نفّذ الجلسة N من docs/plan.md».
2. مهمة واحدة لكل جلسة — لا دمج.
3. الانتقال للجلسة التالية مشروط بـ pytest -x أخضر بالكامل (بما فيه اختبارات
   الجلسات السابقة — لا كسر رجعي).
4. عند أي فشل سلوكي لاحقًا: «الحوار التالي فشل: [النص]. المتوقع: [كذا].
   أصلح وأضف اختبارًا يمنع تكراره».
5. أي متطلب جديد يُضاف للوثائق أولًا ثم يُنفَّذ — الوثائق هي مصدر الحقيقة.
